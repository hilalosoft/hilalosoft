## Research meets engineering

My research interests sit at the intersection of software evolution,
automated testing, and empirical software engineering.

I'm particularly interested in questions like:

- How can automated tests remain useful as web applications evolve?
- What makes a DOM locator resilient to change?
- Where can AI reduce test-maintenance work—and how do we evaluate whether it actually helps?
- How do we turn research prototypes into tools people can reproduce and use?

Alongside research, I build web applications with Laravel, React, and Next.js,
and use Python for experiments, analysis, and developer tooling.
